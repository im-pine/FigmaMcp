# 디자인 브리프

Figma MCP로 쇼핑몰과 관리자 화면을 디자인할 때 기준으로 삼는 문서입니다. 레퍼런스 분석은 Brain_of_Pine `90.4.1 E-commerce`, 관리자 레이아웃은 `90.1.1.1 shadcn-ui 관리자 레이아웃 예시`를 참고했습니다.

## 콘셉트

**우아하면서 따뜻한, 갓 구운 빵 냄새가 나는 베이커리.**
빵 속살 같은 베이지 바탕에 구운 껍질과 초콜릿을 닮은 브라운을 쓰고, 신선한 허브 같은 그린을 포인트로 둡니다.

- 배경은 밝고 단순하게 둡니다. 개성은 **상품 사진**과 **포인트 색 하나**로 냅니다.
- 장식(손글씨, 종이 질감, 스크롤 연출, 360° 회전 등)은 쓰지 않습니다.

## 색

### 스케일

브라운은 브랜드 primary(그린)의 **같은 단계와 같은 밝기**로 맞춘 10단계 스케일입니다. 그래서 같은 단계끼리는 대비가 같고, 단계만 바꿔 가며 두 색을 자유롭게 섞어 쓸 수 있습니다.

| 단계 | brown | primary (브랜드) | 흰 배경 위 대비 |
| --- | --- | --- | --- |
| 50 | `#FCFAF6` | `#f8faf8` | 1.05 |
| 100 | `#F8F2EB` | `#f1f4f1` | 1.11 |
| 200 | `#ECE1D1` | `#dce4db` | 1.3 |
| 300 | `#DFCDB8` | `#c6d4c6` | 1.55 |
| 400 | `#C5A88A` | `#9cb49b` | 2.2 |
| 500 | `#AE835A` | `#719470` | 3.4 |
| 600 | `#986E48` | `#607e5f` | 4.5 |
| 700 | `#805940` | `#4f684e` | 6.1 |
| 800 | `#684432` | `#3e513e` | 8.6 |
| 900 | `#4D3121` | `#2d3b2d` | 11.8 |

카테고리 색에 쓰는 스케일입니다. secondary는 브랜드 핑크이고, honey와 mauve는 brown과 같은 방식(브랜드 primary와 단계별 밝기 일치)으로 만들었습니다.

```css
--secondary-50: #fdfbfb; --secondary-100: #fcf7f8; --secondary-200: #f7eced; --secondary-300: #f3e1e2; --secondary-400: #e9cacc;
--secondary-500: #e0b3b6; --secondary-600: #be989b; --secondary-700: #9d7d7f; --secondary-800: #7b6264; --secondary-900: #5a4849;

--honey-50: #FCF9F4; --honey-100: #F9F3E7; --honey-200: #F1E0C2; --honey-300: #E8CD9D; --honey-400: #D6A551;
--honey-500: #B5822A; --honey-600: #9A6F24; --honey-700: #7F5C1E; --honey-800: #634817; --honey-900: #493411;

--mauve-50: #FBF8FB; --mauve-100: #F7F2F7; --mauve-200: #E9DFE9; --mauve-300: #DCCBDC; --mauve-400: #C3A4C3;
--mauve-500: #A97DA9; --mauve-600: #976597; --mauve-700: #7D537D; --mauve-800: #614161; --mauve-900: #472F47;
```

### 단계별 쓰임 (모든 스케일 공통)

페이지 배경이 brown-100이므로, 글자는 흰 배경 기준보다 한 단계 진한 **700 이상**을 씁니다.

| 단계 | 용도 | brown-100 배경 위 대비 |
| --- | --- | --- |
| 50 | 카드 (배경보다 살짝 밝게) | — |
| 100 | 페이지 배경 | — |
| 200 | 구분 섹션 배경, 배지 배경 | — |
| 300 | 테두리, 구분선 | — |
| 400~500 | 장식, 아이콘, 비활성 요소 (글자 사용 금지) | 3.0 이하 |
| 600 | 흰 글자를 올리는 버튼 배경 (크림 배경 위 글자 사용 금지) | 4.05 |
| 700 | 캡션, 링크 | 5.5 |
| 800 | 본문 | 7.7 |
| 900 | 제목, 어두운 섹션 배경 | 10.6 |

### 적용

**브라운은 바탕과 글자, 그린은 클릭할 수 있는 요소**에만 씁니다.

| 요소 | 토큰 |
| --- | --- |
| 페이지 배경 / 카드 / 구분 섹션 | brown-100 / brown-50 / brown-200 |
| 제목 / 본문 / 캡션 | brown-900 / brown-800 / brown-700 |
| 테두리 | brown-300 |
| 주요 버튼 (장바구니 담기, 주문하기) | primary-600 배경 + 흰 글자, hover primary-700 |
| 보조 버튼 | brown-900 테두리 + brown-900 글자 |
| 링크, 강조 글자 | primary-700 |
| 배지 (장바구니 개수, 주문 상태) | primary-200 배경 + primary-800 글자 |
| 푸터 | brown-900 배경 + brown-100 글자 |

### 카테고리 색

카테고리마다 대표 색을 두고 카드(데스크톱)와 원형 탭·버블(모바일)의 배경에 씁니다. 네 색 모두 **같은 밝기(상대 휘도 0.63)** 로 맞춰 나란히 놓여도 무게가 같습니다. 그린(primary)은 클릭 요소 전용이라 카테고리 색으로 쓰지 않습니다. 예외로 모바일 All 탭은 브라운 계열과 구분되도록 연한 primary-200을 씁니다.

카테고리 카드의 화살표 버튼은 카드 색이 제각각이라, 원형 배경 없이 28px 화살표(선 두께 2.5px)만 primary-700으로 둡니다. 설명은 18px 한 줄입니다.

| 카테고리 | 토큰 | 값 | 스케일 |
| --- | --- | --- | --- |
| 전체 (모바일 All 탭) | `category/all` | `#dce4db` | primary-200 |
| 빵 | `category/bread` | `#DFCDB8` | brown-300 |
| 케이크 | `category/cake` | `#E9CACC` | secondary-400 (브랜드 세컨더리) |
| 쿠키 | `category/cookie` | `#E8CD9D` | honey-300 |
| 음료 | `category/beverage` | `#DCCBDC` | mauve-300 |

브랜드 secondary는 케이크 카테고리 색으로만 씁니다.

## 타이포그래피

| 용도 | 서체 |
| --- | --- |
| 제목 | 한글 세리프 (Noto Serif KR) |
| 본문, UI | Noto Sans KR |
| 섹션 라벨 | Noto Sans KR, 영문 대문자, 자간 넓게 (예: `OUR BAKERY`) |

Pretendard는 Figma에서 사용할 수 없어 Noto Sans KR로 정했습니다. 두 서체 모두 Google Fonts에 있어 `next/font`로 디자인과 같은 서체를 쓸 수 있습니다.

섹션은 **작은 라벨 → 세리프 제목 → 본문 → 버튼** 순서를 반복합니다.

### 모바일

데스크톱 구조를 축소하지 않고 모바일 패턴으로 다시 설계합니다.

| 데스크톱 | 모바일 |
| --- | --- |
| 헤더의 메뉴와 버튼 | 로고만 있는 헤더 + 하단 고정 탭 바(검색 · 장바구니 · 상품 · 마이페이지 · 관리자) |
| 카테고리 카드 4개 (사각 이미지) | 원형 카테고리 아이콘 탭 → 탭하면 아래 상품 목록이 바뀜 |
| 헤더의 카테고리 메뉴 | 가운데 상품 버튼을 누르면 카테고리 버블이 부채꼴로 떠오름 |
| 검색 모달 | 전체 화면 검색 |
| 결제 다이얼로그 | 하단에서 올라오는 결제 시트 |

상세 규칙과 모션 사양은 [Wiki — Design](https://github.com/im-pine/FigmaMcp/wiki/FrontEnd%E2%80%90Design)에 있습니다.

## 이미지

Figma MCP의 이미지 생성(`generate_image`, 기본 모델 `gemini-3.1-flash-lite-image`)으로 만듭니다. 1장에 Figma AI 크레딧 6이 듭니다.
생성된 이미지 URL은 7일 뒤 만료되므로, 생성 즉시 `public/images/`에 저장하고 Figma에도 업로드해 이미지 자리에 채웁니다.

| 종류 | 저장 위치 | 규칙 |
| --- | --- | --- |
| 상품 (12) | `public/images/products/` | 정사각형. 모든 상품을 같은 프롬프트 틀로 생성해 톤을 통일 |
| 배너 · 스토리 (3) | `public/images/hero/` | 데스크톱 배너는 가로형으로 왼쪽을, 모바일 배너는 세로형으로 아래쪽을 비워 글자 자리를 확보 |
| 카테고리 (5) | `public/images/categories/` | 접시 · 받침 · 그림자 · 테두리 없는 오브젝트만, 배경 투명 PNG |

### 상품 사진 프롬프트 틀

```text
Product photo of {상품} on a light wooden cutting board placed on beige linen cloth.
Warm soft morning sunlight from the side, 45-degree camera angle, shallow depth of field,
cream and warm brown tones, plain softly blurred beige background with no props,
elegant warm bakery mood, square composition, no text, no logo.
```

음료는 나무 도마 대신 "in a cream ceramic cup on a saucer"로 바꿉니다.

### 카테고리 이미지 (배경 없는 PNG)

Figma의 이미지 생성 모델은 진짜 투명 배경(알파 채널)을 출력하지 못합니다. `gpt-image` 모델도 투명을 뜻하는 체크무늬를 그림에 그려 넣습니다. 그래서 다음 순서로 만듭니다.

1. 순수 파란색(#0000FF) 크로마키 배경으로, 접시 · 받침 · 그림자 없이 오브젝트만 생성합니다.
2. 로컬 스크립트로 파란색만 지우고(키잉), 가장자리의 파란 기운을 제거합니다.
3. 알파를 1px 안쪽으로 다듬어 테두리처럼 보이는 경계선을 없앱니다.
4. 오브젝트 크기에 맞게 자르고 정사각형 가운데에 배치합니다(여백 10%).

AI 피사체 분리(macOS Vision)는 크림색 접시나 어두운 빵의 가장자리를 잘라내서 쓰지 않습니다.
